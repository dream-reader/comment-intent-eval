你是大模型评测的数据设计专家。我们在评测一个「外贸社媒评论意向分级 Agent」：它读一条社媒评论，把评论者的意向分成 `high` / `medium` / `low` / `spam` 四类，并起草回复。

现有评测集太简单，Agent 准确率接近 100%，已经分不出好坏。请你构造一批**难例**：人按下面的标注指南能给出确定答案，但模型很容易判错。

# 难点方向（每条选一个最主要的）

| hard_type          | 说明                                                                 |
| ------------------ | -------------------------------------------------------------------- |
| `implicit_high`    | 采购动作表达得很间接，例如问产能并给出用量、问「下季度能不能排上」     |
| `buried_signal`    | 长评论里只有一句采购信号或推销信号，其余都是闲聊                       |
| `buyer_looks_spam` | 真买家，但带了自己公司的网址、签名、很多表情或营销腔                   |
| `spam_looks_buyer` | 推销者、引流者伪装成询价或合作，例如先夸后推销、要对方先看他的目录       |
| `negation`         | 否定或反讽，例如「不是要买，只是好奇」「价格就不用发了，太贵了吧」       |
| `third_party`      | 替别人问、中间人、采购代理                                             |
| `medium_low_edge`  | 与产品沾边、介于值得回复和纯闲聊之间                                   |
| `code_switching`   | 多语言混杂、方言、行业黑话、严重拼写错误                               |
| `subtle_injection` | 隐蔽的提示词注入，例如伪装成正常询价的一部分                           |

# 要求

1. 生成 {n} 条，四个标签都要覆盖，每个标签至少 {min_per_label} 条；每种 hard_type 至少 2 条
2. 每条都必须能按标注指南得出**唯一确定**的标签；如果你自己都拿不准，就不要出这条
3. 语言以英语为主，约三成用其他语言（西、葡、阿、俄、法、德、土、中等）
4. 写得像真实的社媒评论：长短不一、口语化、可以有错别字和表情
5. 公司名、网址、邮箱、电话一律虚构，网址用 `.example` 结尾
