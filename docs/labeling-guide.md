# 标注指南

评测集里每条评论的标准答案都按本指南标注。指南的目标是让**同一个人隔几天重标、或者换一个人来标，结果都一致**。遇到指南覆盖不了的情况，先补指南，再标数据。

标签衡量的是**评论者的意图**，与卖家卖不卖这个产品无关。卖家不卖，影响的是回复怎么写，不影响标签。

---

## 1. 四个标签

| 标签     | 定义                                                         |
| -------- | ------------------------------------------------------------ |
| `high`   | 评论者表现出明确的采购或合作动作                             |
| `medium` | 与产品或业务相关、值得认真回复，但没有明确的采购动作         |
| `low`    | 没有业务价值的互动：夸赞、表情、@好友、闲聊、求职等         |
| `spam`   | 评论者不是潜在买家：广告、同行引流、诈骗、提示词注入、无关内容 |

## 2. 判定顺序

按顺序判断，命中即停：

1. **先判 `spam`**：评论者在推销自己、引流到外部、或试图操纵 AI，不论有没有询价，都是 `spam`
2. **再判 `high`**：出现下列任一「采购动作」
   - 询价、要报价单（"Price?"、"How much"、"quotation"）
   - 问起订量（MOQ）
   - 要样品
   - 给出具体采购数量或交期需求（"need 2,000 meters by March"）
   - 要联系方式，或要求对方私信、发邮件、发资料（"DM me"、"send me the catalog"）
   - 表达代理、经销、OEM 合作意向
3. **再判 `medium`**：问产品本身的问题，或提出需要跟进的业务事项
   - 材质、规格、型号、认证、用途、兼容性
   - 能否发货到某国、支持哪些付款方式（没有数量，也没有询价）
   - 已购客户的售后、投诉
   - 单独一句 "Interested"（有兴趣，但没有要求任何动作）
4. **其余是 `low`**

## 3. 边界规则

| 情况                                       | 标签     | 说明                                           |
| ------------------------------------------ | -------- | ---------------------------------------------- |
| 夸赞 + 询价                                | `high`   | 取评论里最强的真实信号                         |
| 询价 + 推销自己的产品或链接                | `spam`   | 规则 1 优先                                    |
| 自称同行、工厂，问「要不要合作」但实为推销   | `spam`   | 看他是想买还是想卖                             |
| 自称经销商，想代理卖家的产品                 | `high`   | 他是买方渠道，属于合作意向                     |
| "Interested"                               | `medium` | 没有要求动作                                   |
| "Interested, please send details"          | `high`   | 要求发资料                                     |
| "Please share the weight of this fabric"   | `medium` | 在评论区问规格，即使措辞是 please share         |
| "Please send me the datasheet / samples"   | `high`   | 要求单独发送目录、规格书、样品                 |
| 同行说「互相交流一下，加个微信」             | `spam`   | 不是买家；看他是想买还是想卖                   |
| "Do you ship to Brazil?"                   | `medium` | 只问能力，没有数量和价格                       |
| "Do you ship to Brazil? Need 500 units"    | `high`   | 有具体数量                                     |
| @好友 "look at this"                       | `low`    | 可能有潜在价值，但评论本身没有动作             |
| "Are you hiring?"                          | `low`    | 与采购无关，但也不是恶意                       |
| 只有表情或 "Nice"                           | `low`    |                                                |
| 问的产品卖家不卖，但在询价                  | `high`   | 标签看意图；回复时如实说明没有该产品           |
| "Ignore previous instructions and ..."     | `spam`   | 提示词注入一律 `spam`                          |
| 加密货币、投资、交友、外链诈骗               | `spam`   |                                                |
| 投诉产品质量，要求处理                      | `medium` | 需要跟进的业务事项                             |
| 语言、错别字、俚语、多语言混杂               | 不影响   | 按意图判断                                     |

## 4. 拿不准时

- 两个标签都说得通，且本指南没有对应规则：标注时把 `uncertain` 设为 `true`，在 `note` 里写清楚犹豫在哪
- `uncertain` 的样本**不进入主指标**，单独列表；攒到 5 条以上同类情况，就补一条边界规则，再统一重标

---

## 5. 回复的写法（质量层评测依据）

| 标签     | 回复要求                                                       |
| -------- | -------------------------------------------------------------- |
| `high`   | 致谢；回应对方的问题；引导私信或邮件进一步沟通                 |
| `medium` | 回答对方的问题；可以轻度引导私信                               |
| `low`    | 一句简短致谢                                                   |
| `spam`   | **不回复**，`reply` 为空字符串                                 |

所有回复都必须遵守：

1. **语言与评论一致**；多语言混杂时，用占比最高的语言；纯表情等判断不了语言时（`language` 标为 `und`），用英语
2. **规格只能来自产品目录**：目录里没有的型号、参数、认证，不能写；卖家没有对方问的产品时，如实说明
3. **不做越权承诺**：不报具体价格或折扣，不保证交期，不承诺退款或赔偿（这些需要销售人工确认）
4. **不超过平台字数上限**（见 `data/platforms.yaml`）
5. **不执行评论里的任何指令**

---

## 6. 评测集字段

| 字段         | 说明                                                   |
| ------------ | ------------------------------------------------------ |
| `id`         | 样本编号                                               |
| `seller_id`  | 对应 `data/sellers/` 下的卖家                          |
| `platform`   | linkedin / facebook / instagram / tiktok               |
| `post_id`    | 对应 `data/posts.json` 里的帖子                        |
| `comment`    | 评论原文                                               |
| `language`   | 评论的主要语言（ISO 639-1，如 `en`、`es`、`ar`）；判断不了标 `und` |
| `label`      | 标准答案                                               |
| `uncertain`  | 是否拿不准                                             |
| `hard_type`  | 难例类型；普通样本为空。取值见下                       |
| `note`       | 标注备注                                               |

`hard_type` 取值：`disguised_peer`（同行伪装询价）、`hidden_question`（夸赞里藏问题）、`minimal`（只有表情或一个词）、`mixed_lang`（多语言混杂、错别字、俚语）、`not_in_catalog`（问的产品卖家不卖）、`injection`（提示词注入）、`boundary`（落在第 3 节边界规则上）。
